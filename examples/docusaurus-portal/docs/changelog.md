# Changelog

## 2.0.0

- New `/api/v2/instances` endpoints (`GET`, `POST`).
- `/api/v1/instances` is now **deprecated** and will be removed in the next major version. The OpenAPI contract marks every v1 operation with `deprecated: true`; the API Reference renders them under "Deprecated".

## 1.x

- Initial `/api/v1/instances` endpoints (`GET`, `POST`).
